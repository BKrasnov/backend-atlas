# Группы блоков в редакторе архитектуры

Цель: выделять блоки рамкой, вместе двигать и копировать Ctrl/Cmd+C → Ctrl/Cmd+V. Работа выполняется самостоятельно в текущей сессии, по ранее выбранному владельцем режиму.

Решение: временный список выбранных ID вместо одного ID; формат сохранённого графа не меняется. В режиме «Выбор» протягивание пустого поля создаёт рамку и выбирает пересекающиеся блоки. Shift+рамка добавляет, Shift+клик переключает блок. Режим «Перемещение» и средняя кнопка сохраняют сдвиг камеры. Группа двигается единым смещением с ограничением по границам поля. Перемещение/вставка/удаление группы — по одному шагу истории. Esc снимает выделение или отменяет жест.

Для копирования используются стандартные browser copy/paste events и clipboardData: маркированный JSON со всеми выбранными блоками и только внутренними связями. Вставка проверяет формат, поля, ID, ссылки и лимиты 30 блоков/90 связей, присваивает новые ID, сохраняет взаимное расположение, подписи и порты, смещает копию и выделяет её. Обычный текст/JSON других приложений игнорируется. Поля ввода и модальные окна сохраняют обычную работу буфера. Стандартные copy/paste сохраняют обмен между страницами атласа.

Файлы: `client/diagram-editor.js` — выбор, жесты, clipboard, история; `client/diagram-editor.css` — рамка и группа; `tests/diagram.cjs` — существующая браузерная регрессия плюс группа; `README.md` — инструкции; исходный HTML обновляется `node scripts/build.mjs`.

Брейншторм проверок до теста: обычный путь — рамка вокруг двух из трёх блоков при изменённом масштабе, видимая рамка и два выделенных блока; движение группы сохраняет расстояние и третий блок, одно undo/redo; Ctrl+C/V создаёт два новых ID и только одну внутреннюю связь с сохранёнными портами/подписью, повторная вставка и undo; Shift+клик меняет состав; текстовый copy/paste не вставляет граф, чужой/невалидный JSON и превышение лимита не меняют данные; обновление страницы подтверждает сохранение группы в API. Проверяются реальные пользовательские действия, без повторения алгоритма реализации. Существующая проверка сдвига пустого поля переключается на режим «Перемещение».
