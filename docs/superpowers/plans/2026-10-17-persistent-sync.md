# Автоматическая синхронизация после перезагрузки

Поручение владельца: запоминать доступ в этом браузере, автоматически подключаться к VPS после перезагрузки и сохранять изменения в существующий JSON-файл. Исполнение самостоятельное, без дополнительных согласований и без изменений API/хранилища VPS.

Выбранный подход: отдельная запись localStorage с адресом, ключом, последней подтверждённой ревизией и признаком неотправленных изменений. Это работает с существующим Bearer API между GitHub Pages и VPS; cookie-сессия потребовала бы другой схемы авторизации между сайтами. Экспорты HTML/JSON и репозиторий не содержат ключ. «Отключить» удаляет сохранённое подключение.

При запуске GET загружает серверную версию. Если остались локальные правки, PUT отправляет их только при совпадении подтверждённой ревизии. При конфликте обе копии сохраняются, направление выбирается явно. До замены локальных данных создаётся резервная копия. Ошибки сети повторяются с задержкой; 401 удаляет ключ, 409 останавливает автоматическую запись.

Брейншторм проверок до написания тестов: обычный путь — подключение, перезагрузка, редактирование и подтверждённый GET сервера; восстановление сети — локальная правка переживает перезагрузку и отправляется после связи; существенный риск — изменённый другим устройством сервер не затирается локальной очередью. Проверить также удаление подключения и отсутствие ключа в HTML-экспорте. Используется существующий браузерный тест с настоящим API и временным хранилищем.
