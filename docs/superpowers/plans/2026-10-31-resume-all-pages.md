# Все страницы резюме в предпросмотре

Подтверждённая причина: PDF содержит две страницы (Aspirity на второй), но профиль и интерфейс показывают только один PNG `previewChunks`. Исправление: сохранить остальные изображения в `additionalPreviewPages` (массив массивов base64-частей), показать все страницы последовательно с подписями и числом показанных страниц. Исходный PDF не изменяется. Старые профили с одним PNG совместимы; для неполного предпросмотра явно указать количество показанных страниц и возможность скачать полный PDF. До 1 МБ на изображение, общий лимит прежний; Blob URL всех страниц освобождаются при закрытии/переходе.

Брейншторм до тестов: реальная регрессия — документ из двух страниц показывает одну. Проверить 2 загруженных изображения с разными байтами и подписи, API/reload и HTML-экспорт второй страницы, точные байты PDF при скачивании. Старый одностраничный/двухстраничный профиль без нового поля должен открываться без потери данных. Отклонять лишние/повреждённые страницы. Мобильный предпросмотр не создаёт горизонтальную прокрутку. Расширить существующий resumes suite; тест первым, единственный финальный запуск после реализации.
