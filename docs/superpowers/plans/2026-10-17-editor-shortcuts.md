# Управление редактором с клавиатуры

Поручение: заметная кнопка полного экрана, Undo/Redo кнопками и клавишами. Причина текущего поведения: обработчик Ctrl+Z/Y висит только на canvas, кнопки палитры и панели уводят фокус. Панель также скрывается при прокрутке.

Решение: закрепить панель внутри виджета; выделить переключатель полного экрана, показывать «Выйти» в развёрнутом виде. Ctrl/Cmd+Z, Ctrl/Cmd+Y и Ctrl/Cmd+Shift+Z работают при видимом редакторе вне текстовых полей; physical code поддерживает русскую раскладку. F переключает полный экран, Esc выходит и отменяет незавершённое соединение. Формы и открытые модальные окна сохраняют обычные сочетания. Обработчики снимаются при уничтожении редактора.
