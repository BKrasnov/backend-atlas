# Обязательный вход в Backend Atlas

Последнее решение владельца заменяет выбранное ранее публичное чтение: на размещённом сайте доступ к атласу и данным открывается только после подтверждения ключа сервером. Публичное чтение не внедрялось; API продолжает требовать Bearer-ключ для GET и PUT.

Дизайн: отдельный обязательный dialog без закрытия и без отмены через Escape. До подтверждения ключа `.app` скрыт и inert. Правильный ключ вызывает GET, загружает серверную версию и открывает приложение; сохранённый ключ проверяется автоматически при перезагрузке. Неверный ключ и ошибки сети оставляют блокировку и показывают причину. Автономный HTML без адреса API сохраняет локальный режим. Существующие незавершённые правки и конфликт ревизий обрабатываются прежним механизмом без потери данных.

Брейншторм проверок до кода: чистый браузер видит обязательный вход, Escape его не закрывает; неправильный ключ не раскрывает атлас; правильный ключ загружает профиль с сервера без выбора направления; перезагрузка с сохранённым ключом открывает профиль; недоступный сервер при повторном входе не раскрывает локальный кэш; отключение снова блокирует доступ. Сохраняются проверки автозаписи, конфликтов и отсутствия ключа в экспортах. Тесты записаны до реализации, запуск только после готовности.
