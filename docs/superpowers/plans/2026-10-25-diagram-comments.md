# Комментарии на архитектурной схеме

Запрос: комментарии «как в Figma» на показанном редакторе. Область — схемы задач. Режим C/«Комментарий», клик по блоку/полю, номерная метка и панель обсуждения. Ответы, редактирование сообщений, решение/повторное открытие, список с показом решённых, удаление с undo. Один существующий профиль/ключ, без новых аккаунтов и backend.

Хранение: необязательный `sketch.comments`, массив обсуждений `{id,x,y,nodeId?,resolved,messages:[{id,author,text,at}]}`. Для nodeId координаты относительные; для свободной метки — мировые. При удалении блока обсуждение отсоединяется и остаётся в текущей точке; undo восстанавливает привязку. Данные входят в общую историю, снимок решения, JSON/HTML и нынешнюю синхронизацию. Старые схемы открываются с пустым массивом. Проверка структуры единая в модуле, вызывается импортом. Тексты экранируются, лимиты — 100 обсуждений, 50 сообщений по 4000 символов; автор 100 символов.

UI: кнопки «Комментарий» (C) и «Обсуждения N», фиксированного экранного размера SVG-метки с клавиатурным открытием, панель поверх правой части поля. На узком экране панель занимает нижнюю часть поля; закрывается отдельно, не мешает вводу и прежним сочетаниям. Черновик не сохраняется до отправки, Ctrl/Cmd+Enter отправляет. Выбор/перемещение закрывают панель. Полный экран сохраняет доступ к панели.

Брейншторм до тестов: открыть старую схему; C и клик на блок — безопасный текст с HTML-символами и ответ, движение блока переносит метку; отдельная метка поля; редактирование первого сообщения сохраняет ответ; решение скрывает метку, показ решённых и повторное открытие возвращают её; удаление и одно undo; удаление блока оставляет обсуждение на месте, undo возвращает привязку. После reload/API, снимка и HTML тексты/привязки не теряются. Проверить textarea не перехватывается клавишами редактора, mobile и fullscreen. Существующий diagram suite даёт регрессию связей, группы/буфера, отмены и SVG. Тесты пишутся первыми, запуск — финальным общим прогоном.
