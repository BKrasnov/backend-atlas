# Обновление Python-резюме

Добавить предоставленные владельцем ФИО, контакты, город и образование. Дополнить примеры опытом разработки микросервисов, участия в архитектурных решениях, интеграций с DataHub API, Grafana/Prometheus и Grafana Loki, WebSocket-сервисом фильтров. После уточнения владелец поручил выбрать типичные Python-библиотеки самостоятельно: они относятся к учебным примерам; прежний условный стаж и непроверенные компании/периоды сохраняют пометку черновика. DataHub описывается нейтрально как API платформы без предположений о её продукте и SDK.

Сохранить прежний PDF, обновить локальный источник и PDF с кликабельными контактами; перерисовать все страницы и проверить извлечённый текст. PDF может занять две страницы: не уменьшать шрифт ради одной. Обновить PDF/PNG в существующей версии `python-backend` на VPS, сохранив остальные поля workspace; предварительно сделать резервную копию и использовать If-Match. Ссылка `#resume` должна вести в существующий `#resumes`, без второго списка.

Минимальный брейншторм тестов до кода: пользователь открывает присланную ссылку `#resume`, проходит вход и видит список; существующий тест резюме проверяет приватность, API, просмотр, точные байты скачивания и мобильную ширину. Изменить его начальный адрес и проверить канонический маршрут. Запуск один раз после готовности фичи. Для документа дополнительно проверить текст, ссылки, число страниц и все отрисованные страницы, без новых модульных тестов на формулировки.

Документация для подбора библиотек: FastAPI WebSockets, HTTPX AsyncClient, Prometheus Python ASGI, python-json-logger, aio-pika и aiokafka; логирование через Grafana Alloy в Loki. Эти ссылки подтверждают совместимость примеров, а не фактический стаж кандидата.
