# Список резюме

Запрос: вкладка «Список резюме» и ранее созданный PDF Python Backend Developer. Одна версия, текущая пометка об условном стаже сохранена. Новый текст резюме не создаётся.

Решение: маршрут `#resumes` в боковом меню после профиля. Карточки с названием, тегами, статусом черновика, датой, числом страниц и размером; просмотр страницы внутри атласа и скачивание PDF. Исходный PDF и PNG предпросмотра хранятся в `profile.resumes` в существующем JSON на VPS, доступны после нынешнего входа по ключу. В публичную сборку добавляются только интерфейс и валидация. Файлы разбиты на base64-части по 32000 символов из-за существующего лимита строки API 50000. Без базы, новых серверных endpoints и публичного каталога документов.

Поля версии: id, title, summary, tags, draft, experienceYears, pages, fileName, addedAt, pdfChunks, previewChunks. Старые профили получают пустой список. Проверяются типы, уникальные ID, лимиты и сигнатуры PDF/PNG. Превью — PNG через временный Blob URL; скачивание возвращает исходные байты PDF. URL освобождаются при закрытии просмотра/смене раздела. Файлы входят в JSON/HTML-экспорт; просмотр и скачивание не изменяют профиль.

Брейншторм до тестов: старый профиль без списка и пустой экран; открыть вкладку, загрузить версию в тестовый профиль, проверить карточку/условный стаж, открыть и закрыть превью, скачать идентичные байты; API/reload и новое устройство после входа показывают тот же файл; HTML содержит файл и не содержит ключ; повреждённый формат отклоняется; мобильные кнопки помещаются по ширине. Существующий browser suite проверяет прежний вход/синхронизацию. Тесты пишутся первыми, запуск — одним финальным прогоном.
